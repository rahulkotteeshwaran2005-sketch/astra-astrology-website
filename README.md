# 🌌 ASTRA – Astrology Website

A modern astrology consultation platform built using Django and Python.

## ✨ Features

- User Registration and Login
- Astrologer Listings
- Astrologer Profiles
- Consultation Booking
- Date and Time Selection
- Booking Confirmation
- Responsive User Interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- SQLite3
- JavaScript

## 📂 Project Structure

- studentapp/ – Main application
- templates/ – HTML templates
- static/ – CSS and images
- manage.py – Django management file

## 🚀 How to Run

1. Clone the repository.
2. Install Django:

   pip install django

3. Run migrations:

   python manage.py migrate

4. Start the server:

   python manage.py runserver

5. Open http://127.0.0.1:8000/ in your browser.
